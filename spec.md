# BiteBot Specification & Messaging Channels Guide

## 1. Overview
BiteBot is an AI-powered nutrition assistant built with **Streamlit** and **Google Gemini (`google-genai`)**. Users can upload meal images or input meal text descriptions to estimate calories and macronutrients. At the end of a session, BiteBot compiles a summary of all discussed meals and sends it directly to the user's Telegram chat.

---

## 2. Messaging Implementations

### A. Telegram (Active Implementation)
- **Mechanism**: Direct HTTPS requests to Telegram Bot API (`https://api.telegram.org/bot<BOT_TOKEN>/sendMessage`).
- **Required Secrets**:
  - `TELEGRAM_BOT_TOKEN`: The API token generated by [@BotFather](https://t.me/BotFather).
- **User Input**:
  - `Telegram Chat ID`: User's numeric Chat ID (retrieved via [@userinfobot](https://t.me/userinfobot) or by sending a message to your bot).
- **Advantages**:
  - 100% Free with no sandbox or template approvals required.
  - No third-party account limitations (unlike Twilio Sandbox restrictions).
  - Simple HTTP POST call without heavy dependencies.

---

### B. WhatsApp (Twilio)
- **Mechanism**: Twilio Messaging REST API using Content Templates.
- **Required Secrets**:
  - `TWILIO_ACCOUNT_SID`
  - `TWILIO_AUTH_TOKEN`
  - `TWILIO_WHATSAPP_FROM`
  - `TWILIO_CONTENT_SID`
- **User Input**:
  - `WhatsApp Number`: E.164 formatted phone number (e.g., `+14155552671` or `+91XXXXXXXXXX`).

---

### C. Gmail (SMTP Alternative)
- **Mechanism**: Python built-in `smtplib` and `email.mime` via Gmail SMTP server (`smtp.gmail.com:587` or `465`).
- **Required Secrets**:
  - `GMAIL_ADDRESS`: Sender email address (e.g. `yourname@gmail.com`).
  - `GMAIL_APP_PASSWORD`: 16-character Google App Password (generated under Google Account > Security > 2-Step Verification > App Passwords).
- **User Input**:
  - `Recipient Email`: Target email address.

---

## 3. How to Set Up Telegram Messaging

1. **Create your Bot**:
   - Open Telegram and search for [@BotFather](https://t.me/BotFather).
   - Send `/newbot` and follow the prompts to choose a name (e.g. `BiteBot`) and username.
   - Copy the HTTP API token provided by BotFather.

2. **Add Bot Token to `.streamlit/secrets.toml`**:
   ```toml
   GEMINI_API_KEY = "your-gemini-api-key"
   TELEGRAM_BOT_TOKEN = "123456789:ABCdefGHIjklMNOpqrSTUvwxYZ"
   ```

3. **Get Your Telegram Chat ID**:
   - Open Telegram and search for [@userinfobot](https://t.me/userinfobot).
   - Press Start to see your numeric `Id` (e.g., `987654321`).
   - Open your newly created bot in Telegram and click **Start** so it has permission to message you.
   - Enter that Chat ID into BiteBot.
